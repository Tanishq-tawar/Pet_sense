# 🐾 Pet Sense — AI-Powered Pet Health Monitoring

> **Important:** Pet Sense is currently running in **Demo Mode**. All analysis results are generated by a rule-based placeholder, not a trained AI model. Results are preliminary observations only and are **not medical diagnoses**. Always consult a qualified veterinarian.

## Overview

Pet Sense is a full-stack web application for monitoring dog health through photo and video uploads. It provides preliminary visual observations, maintains pet health profiles, tracks vaccinations, and sends reminders for vet checkups.

**Currently supported breeds:**
- Labrador Retriever
- German Shepherd *(expandable by adding records to the `Breed` table)*

## Quick Start

### Prerequisites
- Python 3.10+ (tested on 3.14)
- Node.js 18+

### 1. Backend Setup

```powershell
cd d:\Pet_Sense\backend

# Create virtual environment (already done if venv/ exists)
python -m venv venv
.\venv\Scripts\python.exe -m pip install --prefer-binary -r requirements.txt

# Run migrations
.\venv\Scripts\python.exe manage.py migrate

# Seed supported breeds
.\venv\Scripts\python.exe manage.py seed_breeds

# (Optional) Create admin user
.\venv\Scripts\python.exe manage.py createsuperuser

# Start server
.\venv\Scripts\python.exe manage.py runserver 8000
```

Backend runs at: **http://localhost:8000**  
Admin panel: **http://localhost:8000/admin/**

### 2. Frontend Setup

```powershell
cd d:\Pet_Sense\frontend

# Install dependencies (already done if node_modules/ exists)
npm install

# Start dev server
npm run dev
```

Frontend runs at: **http://localhost:5173**

The Vite dev server proxies `/api` and `/media` requests to Django at port 8000.

## AI Analysis Pipeline

The pipeline is modular and replaceable:

```
ai_pipeline/
├── base.py          # BaseAnalyzer (abstract), Observation + AnalysisResult dataclasses
├── demo_analyzer.py # DemoAnalyzer — rule-based, clearly labelled DEMO MODE
└── pipeline.py      # run_analysis(upload) orchestrator
```

**To integrate a real model:**
1. Create a class inheriting from `BaseAnalyzer` in `ai_pipeline/`
2. Implement `analyze(image_path: str, pet: Pet, breed: Breed) -> AnalysisResult`
3. Update `pipeline.py` to import and use your class
4. Never set `mode = 'demo'` on production results

**Demo mode behavior:** The `DemoAnalyzer` performs basic image checks (blur, brightness, aspect ratio) and returns clearly-labelled illustrative observations. It never generates fake confidence scores or medical claims.

## Security

- Passwords hashed via Django's PBKDF2 (argon2-ready)
- JWT access tokens: 24h lifetime; refresh tokens: 14 days with rotation + blacklist
- Object-level authorization: every queryset filters by `request.user`
- File upload validation: MIME type + size limits (configurable in `.env`)
- CORS configured for `localhost:5173` (dev); update `CORS_ALLOWED_ORIGINS` for production
- Sensitive keys in `.env` — never committed (`.env.example` provided)
